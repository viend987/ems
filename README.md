# LSFD Field Reference

Web panduan roleplay Los Santos Fire Department (LSFD) untuk JGVRP:
<https://ems.viend.my.id>

### Fitur
- **Mode Operasional**: Alur SOP tindakan lapangan (DR-XABC, DEAT, fraktur, obat ILS, radio & kode status) siap salin sekali klik ke clipboard.
- **Form Laporan (BBCode)**: Generator form BBCode forum (Patrol Log, Patient Care Report, Maintenance, Plastic Surgery, Criminal Record).
- **Mode Panduan (Guide)**: Rujukan teori doktrin & rules (Kalkulator Ketentuan Player Kill, Terminologi Anatomi & Cedera).
- **Pencarian Cepat & Bilingual**: Cari command/anim/tindakan dalam bahasa Indonesia atau Inggris, plus toggle Dark/Light mode.

### Menjalankan Lokal

```bash
npm install
npm run dev
```

### Testing & Lint

```bash
npm test
npm run lint
```
